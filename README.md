# NodeSpace Sync releases

Signed and notarized installers for NodeSpace Sync. Each release holds:

- `NodeSpace-Sync.pkg`, the installer (Apple Developer ID signed and notarized)
- `NodeSpace-Sync.pkg.sha256`, its SHA-256 checksum

Please download through the sync download page; it shows the current version and checksum.
This repository contains release assets only. The source lives elsewhere.
